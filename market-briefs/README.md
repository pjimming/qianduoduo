# 每日市场简报源文件

每日简报以 Markdown 为唯一可编辑源文件，文件名必须使用 `YYYY-MM-DD.md`。

- 页面路由：`/investment/briefs`
- 默认打开最新日期，只列出实际存在的简报文件。
- 文件首行建议使用一级标题，例如 `# 2026-10-28 每日市场简报`；页面会将其作为正文标题。
- 常规结构：收盘概览、市场为何这样走？、结构性亮点：当日 1–2 点结论、关键资金信号、政策面信号、估值参考、后续影响与展望、结论。第三章标题直接写当天结构结论；第七章固定分设“短期（1-2 周）”和“中期（1-3 个月）”。 结构性亮点必须同时包含“强势板块”和“弱势板块”两个三级小节，各列至少一个相对强势、相对弱势方向，结合涨跌幅、成交或资金证据说明；普涨或普跌时使用相对强弱，数据不足写“未获取到”，不得硬凑或将弱势写成买入机会。
- 估值参考允许读取并分析市场分析师文章、券商研报和可靠财经媒体原文，不要求交易所或指数公司官方披露；注明作者/机构、原文链接、文章发布日期、估值数据截至日和指标口径（如 PE TTM、静态/预测 PE、PB，以及分位区间和方法）。允许统计口径差异，逐项标注并统一提示“统计口径可能存在差异，仅供参考”，不同来源不强行拼接或直接比较。可引用最近可得数据，明确其与简报日期的时差；文章未披露的字段写“未获取到”，不猜测，不把旧数据当成当日估值。区分文章观点与本稿分析，不能只凭搜索摘要填数。
- 数字、日期和事件来源必须可核验；字段缺失时写“未获取到”，不得估算补齐。
- 市场判断与投资建议分开表达，不写入 R2 账本或账户事实。
- 本目录属于本机投资资料，不进入 GitHub Pages 白名单。
