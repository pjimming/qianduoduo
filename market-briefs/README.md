# 每日市场简报源文件

每日简报以 Markdown 为唯一可编辑源文件，文件名必须使用 `YYYY-MM-DD.md`。

- 页面路由：`/investment/briefs`
- 默认打开最新日期，只列出实际存在的简报文件。
- 文件首行建议使用一级标题，例如 `# 2026-10-28 每日市场简报`；页面会将其作为正文标题。
- 常规结构：市场概览、风格与板块、关键事件、报告库联动、下一交易日关注、一句话结论。
- 数字、日期和事件来源必须可核验；字段缺失时写“未获取到”，不得估算补齐。
- 市场判断与投资建议分开表达，不写入 R2 账本或账户事实。
- 本目录属于本机投资资料，不进入 GitHub Pages 白名单。
