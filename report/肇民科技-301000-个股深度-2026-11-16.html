01 / 一页结论

研究优先级中：制造能力成立，机器人利润弹性尚待证明

判断：肇民科技值得继续跟踪精密功能件的产品升级，但目前不足以把它定义为人形机器人的确定性稀缺供应商。最有价值的下一步，是确认机器人业务从逐步量产走到可量化收入，以及汽车与家电基本盘能否恢复利润率。

判断维度当前结论改变判断的证据
产业位置工程塑料精密件及配套模具，汽车零部件二级供应与家电零部件制造；材料应用和成型工艺层。具体产品获得客户验证、稳定交付及更高价值量。
利润捕获认证、复杂模具及批量一致性有价值；独家地位、机器人单机价值量和价格权未获取到。可核验客户、产品收入、毛利和现金回收，优于泛化的轻量化叙事。
市场阶段判断为主题预期活跃、盈利验证滞后；不能仅凭涨价断定机构持续增配。价格与板块相对强弱、持续成交和盈利上修共同改善。
退出状态核心新业务假说仍待验证；整体盈利走弱已经触发降温观察，尚无证据宣告机器人路线失效。订单取消、认证失败、毛利继续恶化或放量破位触发下调。

最强反方理由：客户可能把新零件分配给多个合格供应商，或者选择金属、较低成本树脂与其他结构方案。即使机器人放量，单件价值、份额和毛利不足，也可能无法抵消原有业务的利润下滑。此为研究推断，须用产品经济性验证。

02 / 产业链与瓶颈

卡点在复杂功能件的可靠制造，尚未证明是供给短缺

公司半年报说明，业务为精密注塑件和配套精密注塑模具；汽车产品覆盖热管理、电子水泵、水阀、空气悬架等，家电产品覆盖智能座便器、热水器及净水器功能部件。公司披露的主要客户包括三花智控、皮尔博格、舍弗勒、均胜电子及A.O.史密斯等。这些是公司整体业务客户，不能据此认定它们是机器人产品客户。[2，第三节，主要业务]

研究逻辑：轻量化与功能集成需求 → 特定零件需要材料性能、尺寸稳定性及耐久性 → 模具设计、材料处理和成型窗口决定良率 → 客户认证及重复订单 → 利用率、产品价格和回款共同决定股东利润。

层级 / 路线约束与替代肇民的位置与利润含义
终端整机 / 系统汽车、家电与机器人需求节奏不同；机器人的规模推广仍取决于性能、成本和使用场景。整机景气不能直接等同公司订单；先查具体零件进入哪个平台。
树脂 / 材料PA、PPS、PEEK等性能和成本不同；选材取决于零件要求，不能一概由PEEK替代。公司是材料应用与精密件制造商。半年报称原料包括工程塑料粒子，市场供应较充足；不应套用PEEK树脂稀缺逻辑。[2，采购模式]
模具 / 精密成型复杂结构、嵌件、收缩与批量一致性提高开发难度；客户审核与认证周期长。这是更可信的工艺壁垒。其价值要落实到良率、复购和毛利，尚无公开证据证明机器人零件独供。
金属 / 其他塑料方案金属加工、压铸、其他工程塑料及结构重新设计构成替代；高载荷、高温和磨损条件须分别验证。“以塑代钢”适用于满足要求的零件，并非整机全面替代。若替代材料满足性能且成本更低，议价权会下降。
扩产 / 其他供应商同类模具注塑企业、客户第二供应源及客户自制均可能扩充供给，实际机器人合格供应商名单未获取到。新增产能既可能接单，也可能增加折旧与闲置成本；投资完成不代表产能短缺。

披露事实来自[2，第三节主要业务、经营模式、核心竞争力]；替代路线与利润传导为技术经济推断，未据此认定任何具体供应商已进入同一客户。

03 / 商业化与证据阶梯

从开发新品进到逐步量产，收入规模仍是缺口

业务 / 阶段已确认披露不能外推的结论下一验证点
汽车与家电基本盘
规模化经营		半年报列出多类汽车功能件规模化量产及长期客户；泰国基地已开始量产。[2]未获取到各机器人客户身份；整体收入不能当作机器人收入。新车型 / 新品类收入、海外利用率、产品毛利及客户回款。
机器人新品
开发 → 逐步量产		半年报说明共同开发多款新品；11月活动记录进一步称正在逐步实现量产，收入占比还较小。[2][3]尚不支持特定头部整机客户、独供、确定大订单、稳定规模交付或重大利润贡献。可核验产品名称、量产批次、付费交付、收入金额与毛利。
新基地与扩产
资本投入		半年募资专项报告显示相关一期项目累计投入进度97.60%，当时预计可使用时间为2026年9月；11月仍提及筹备新的生产研发基地。[4][3]97.60%是资金投入进度，既不是产能利用率，也不是机器人收入占比；不能把不同基地混为同一项目。逐项目核对竣工、转固、客户验收、利用率与收入，未获取到最新逐项验收表。

主题利润计算框架：终端实际产量 × 对应零件单机价值量 × 公司供货份额 × 可实现利润率，再扣新增研发、认证、折旧及融资成本。上述四个机器人专属参数尚未获取到，故本报告不填入收入预测，也不把全部公司增长归因于机器人。

研究顺序：①核对汽车与家电毛利下降的产品和地区来源；②索取机器人可量化收入与订单证据；③核对新产能的转固、良率和回款；④待这些证据改善后，再比较同类制造商的利润和估值。该顺序表达研究价值，不表示预期涨幅。

05 / 市场叙事、估值与资金

主题弹性已被交易，缺少收入证据时不宜按纯度定价

官方事实：11月最新公司问答支持逐步量产，也明确营收占比小。市场解释：轻量化、PEEK和机器人供货弹性容易成为定价线索。本报告推断：股价在盈利下滑后仍出现较强阶段涨幅，市场至少在交易部分新业务预期，但不能证明涨幅由哪一事件独立造成。[3][6]

证据观察含义与限制
事件前后价格10月28日25.46元，10月29日24.05元（−5.54%）；11月4日23.40元，11月5日28.08元（+20%）；11月13日28.00元。季报披露日股价下跌，之后主题交易升温；相关性不等于单一因果。11月4日至13日约+19.66%。[6]
成交与日内波动11月6日成交约2,210.5万股、6.18亿元；13日约1,189.8万股、3.36亿元；11月10日高点31.86元。13日收盘较该高点回落约12.12%，热度与回撤并存。按9月底约2.30亿流通股粗算，13日换手约5.17%，非交易所精确口径。[6][7]
龙头、广度、相对强弱未获取到同口径机器人板块涨跌家数、龙头成交与基准同期收益。可确认个股波动，不能据此认定板块主升或公司取得相对强势。下一步需补齐板块与创业板指比较。
资金结构没有完整的每日融资余额、机构持仓变化与可归因资金流序列。不使用“主力净流入”替代真实持仓，不把调研名单视为买入；拥挤度判断为局部交易活跃，证据不完整。
解禁、减持与转债已核对9月股权激励归属；转债2027-01-15进入转股期，9月披露调整转股价至33.76元。未来转股与潜在价格修正要持续跟踪；历史调整价不是支撑位，未确认研究日仍无后续调整。后续减持与新增解禁明细待完整复核。[5][9]

估值重算：用11月13日收盘28元 × 9月底股本243,588,856股，得到约68.20亿元市值。以已披露前三季度归母净利润简单乘4/3年化，约1.079亿元，对应约63.2倍；该指标不是TTM市盈率，也不是全年预测，没有处理季节性和后续股本变动。暂不采纳第三方页面未充分解释的市盈率口径。[1][6]

仅作预期敏感性检验：若全年归母利润分别达到1.5亿、2亿或3亿元，同一68.20亿元市值对应约45.5、34.1或22.7倍。这里的利润是假设值，不是预测或目标；需要具体订单、毛利和成本证据支撑，不能仅靠机器人概念填入。

数据限制：研究日为11月16日，报告主动采用13日已核验收盘，不把盘中行情当收盘。本轮网络检索后段出现连接故障；已通过直连披露转载页继续核对财务和最新公告标题，但市场广度、完整减持与监管穿透仍未完成，故不作当前买入吸引力判断。

06 / 催化与验证登记

下一催化应能补上收入、利润或回款的一环

类别 / 事件验证时间先行指标与观察阈值失效条件
条件性：机器人量产变为规模收入下一次公开调研及2026年报，实际披露日期未获取到要求首次可量化收入或可核验付费交付；收入占比达到5%可作为提高研究深度的自定阈值，不是公司目标。持续只披露开发与量产表述，无收入、订单和现金补证，研究优先级不提高。
条件性：基本盘盈利修复2026年报及下一季度报告观察单季扣非同比改善、毛利率停止下滑；滚动经营现金 / 归母达到80%以上作为内部观察阈值。连续两期扣非同比下降且毛利进一步走弱，下调研究优先级。
条件性：新产能验收与消化下一次募资使用报告及年报逐项目看转固、利用率、产品收入；存货同比增速不持续高于收入，库龄与跌价未恶化。新增产能闲置、长期低良率，或存货跌价扩大而收入未兑现。
已确认日程：转债进入转股期2027-01-15起；生效安排以后续公告复核核对最新转股价格、余额、实际转股及股本变化；不推断必然转股。条款、时点发生后续正式变更时更新登记。
未证实传播：特定头部机器人客户 / 独供正式客户、合同或公司有效公告出现时需明确客户与产品范围；互动概念、调研参与和产业链间接关系不够。未取得证据前不进入订单、收入或估值模型。

5%、80%及连续两期为本报告自定研究监控阈值，仅用于决定何时继续核查，不是上市公司承诺或机械交易指令。

07 / 退出与监控

基本面与资金结构分别设失效条件

维度触发下调或退出研究假说的证据当前状态
基本面关键客户取消项目 / 认证失败；或连续两期毛利与扣非同比继续恶化，扩产未带来收入回报。利润压力已出现，等待产品与地区拆分；尚未获取到取消订单事实。
叙事所谓重大机器人供货被正式否认；零件路线被替换，或主题收入长期无法量化。逐步量产成立，纯度与利润弹性未验证。
价格 / 资金在可比板块稳定时，连续3个交易日收盘低于11月4日参考收盘23.40元，且成交放大至此前20日均量的1.5倍以上；或相对强弱持续恶化。只是预设失效规则，当前未获取完整基准和20日均量，未宣告触发；参考价不构成支撑保证。
治理 / 融资出现资金占用、重大监管问题、异常减持或新增融资显著加重摊薄，且不能用项目回报解释。转债与激励需持续核对；未完成全面治理排查。
筹码 / 现金持续融资杠杆上升、持有人分散且股价承接转弱；经营现金与利润长期背离、存货跌价明显扩大。每日融资和筹码序列缺失；现有现金转换与存货已列需关注。

提升研究优先级需要“机器人付费规模证据 + 主业利润企稳 + 现金回收改善”至少形成相互支持；只有产品开发或股价上涨，不足以补齐盈利链条。
