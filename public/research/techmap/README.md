# A股科技全景图（研究资料）

本目录是 R2 理财应用中的独立研究资料模块，不属于 R2 理财产品池，不参与收益账本、产品排序或选品结论。

> 归档说明：应用运行时已改为 `src/components/techmap/` 中的原生 Vue 组件，本目录仅保留原始静态页面作为资料来源与回滚参考，不再通过 iframe 加载。

## 内容

- `index.html`：画布脑图版，支持缩放、拖拽、搜索和展开。
- `tree.html`：树状版，支持逐级折叠和搜索。
- `table.html`：表格版，支持搜索、门类筛选和打印。

三页共用同一份静态快照：8 大门类、40 个子行业、156 个细分方向、750 家代表公司。

- 数据日期：2026-09-16
- 原始目录：`C:\Users\Administrator\Documents\Codex\2026-09-16\a-cpo-pcb-a\outputs\site`
- 数据性质：产业地图与事实索引，不构成投资建议；个股信息以最新公告和定期报告为准。

## 更新方式

来源站点为三个自包含 HTML 文件。更新时请同时替换 `index.html`、`tree.html`、`table.html`，并更新本文件中的数据日期。三页的数据是分别内嵌的，不能只替换其中一个文件。

应用内页面会隐藏来源站点右下角的“版本”切换器，版本切换由 Vue 容器页统一提供。
