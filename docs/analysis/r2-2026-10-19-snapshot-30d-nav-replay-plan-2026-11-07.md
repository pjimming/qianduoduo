## 3. 日期与30天口径

| 项目 | 约定 |
| --- | --- |
| 选品输入日期 | 2026-10-19快照；具体决策时间须验证信息可见性及交易截止时间 |
| 模拟建仓 | 按当时适用申购规则、确认日期及对应净值处理，不直接用决策日净值买入 |
| 30天收益 | 从确认适用净值起计算30个自然日，终点净值与估值规则、非估值日处理方式预先固定 |
| 日期示例 | 若2026-10-20确认，则满30日为2026-11-19；这只是条件示例，实际确认日尚待核验 |
| 当前观察状态 | 记录日为2026-11-07，尚未到示例观察终点，不能提前给出完整一个月收益 |

逐产品“确认后30日收益”用于比较选品有效性。若不同产品确认日期不同，其30日终点也不同，不直接拼成同一交易日的组合收益。组合层另设统一观察截止日，明确各产品实际持有天数及在途资金；若取11月19日为统一观察节点，未满30日的产品必须标出，不冒充完整30日持有。

锁定期超过30天的产品仍可观察第30天净值，但其结果标为账面收益；不得假设第30天可赎回。可兑现收益另按真实可赎窗口评价。

## 4. 金额、可买性与执行约束

两套策略各使用独立模拟本金100,000元，满仓目标100%、现金目标0。保持已确定的产品准入、单只、收益证据档位及策略集中度规则；期限目标和偏离依照当前比较口径单列。

用户额度规则保持一致：**当时公开状态已确认可买，且金额空白时，按“大于5,000万元可买”处理；不设置明确额度优先。** 明确披露少量余额的产品按实际金额约束。历史状态未知不等于状态可买，不能用今天的状态或额度补填10月19日。

10月19日快照缺少完整历史额度状态和部分条款，实施前须形成覆盖审计：有证据的执行条件按证据模拟，缺失条件明确列为假设。无法证明当时可买时，可交付条件性的净值收益回放，不宣称完整组合当时一定可成交。

资金未分配时依次寻找当时的合格替补、补足已选产品，再按已冻结规则处理期限偏离；确实无法在约束内满仓时，该批次记为不可执行，不用未来产品或放宽风险门槛强行补齐。申购确认和赎回到账产生的在途资金须计入账户，不能为展示满仓而假装已起息。

## 5. 收益计算

1. 使用真实单位净值、分红和拆分资料重建份额与现金流，不用“年化×30/365”代替实际收益。
2. 无分红、拆分且无需额外费用时，单产品区间收益率为“期末单位净值÷确认适用单位净值−1”。存在相关事项时按实际份额和现金流计算；累计净值只用于核验，不直接当作复权总回报净值。
3. 已计入净值的费用不重复扣除；额外申赎费用、确认及到账空档按可核验条款计入，未知项目及敏感性另列。
4. 缺失净值不补成0收益，不用未来净值反填历史估值。周末、休市及披露滞后依据产品实际规则处理，终点取值方法事前固定。
5. 组合使用实际模拟份额、现金及在途资金逐日估值，计算累计收益和组合最大回撤；不以单产品回撤加权代替组合回撤。
